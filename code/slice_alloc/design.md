# 研究点1：低空智联下的多模态网络切片智能分配（最终RL版本）

本版将研究点1明确为**共享空地资源约束下的业务接纳、网络模态绑定和功能部署联合决策**。主方法为验证集选定的单模型、带可行性掩码的强化学习策略；不使用规则兜底、示范训练或模型集成。不预设学习方法优于规则，结论由新留出实验决定。旧正式报告保持不变，诊断与修订结果另存。

## 研究问题和论文范围

论文题目仍为《面向低空智联的多模态网络切片技术》。研究点1负责到达时的初始分配；研究点2以后研究可观测历史驱动的需求/资源预测；研究点3以后研究运行期QoS监测和主动调整。本轮只实现第一项。协议原生的被动映射更新与NDN转发不是研究点3；对已接纳合同的公开结束时间做资源日历不是研究点2；回报分位数不是需求预测。

低空智联：平台、双边缘、双AP与12架80m高度无人机；4架巡检、8架驻留，巡检速度5/8/11m/s，真实WiFi关联和位置变化。适用范围为简化空地WiFi场景，不推断到城市干扰、蜂窝网络、三维避障或任意无人机集群。

多模态网络：IP、受限EID-RLOC、原生NDN三类网络承载。这里的“模态”指网络标识/寻址/转发与内容处理机制，不是图像、音频等数据模态。IP在准入时绑定定位；ID提供被动映射更新与重试；NDN提供命名获取、Interest聚合和在网缓存。IP方案没有连接迁移；不能写成“IP天然无法支持移动”。ID不是完整LISP协议实现。

网络切片：每份合同形成具有租户、生命周期、SLA、功能位置及资源预约的逻辑切片；三模态共享17维资源账本。实现的是准入和预约层隔离；没有每租户无线调度器，也没有确定性端到端QoS保证。无线预约是平均包络，真实报文违约必须保留。

## 合同、动作与目标

业务统一为下行态势图像、共享地图和任务命令。请求只给业务语义、消费者、起止时间、周期、载荷、内容版本、可复用属性和SLA，不给模态标签；同一合同由不同协议执行时保持载荷、发送轮次、消费者及SLA一致。物理拓扑、容量、移动、命名和业务分布完全沿用已核验v1。

到达时动作 a=(接纳/拒绝, 模态, 边缘位置, 映射位置或缓存位置)。最多11个动作包含拒绝。协议适用性和完整已签资源日历共同产生动作掩码；双消费者业务不进入仅实现单端点的ID。可复用对象才开放缓存。拒绝始终合法，不用失败动作罚分代替约束。

主要目标：在共享资源约束下最大化一回合实际SLA成功合同数 E[Σ_i Y_i]，Y_i由原生emit/complete和期限比例核算；拒绝记失败。学习采用gamma=1，有限回合，无折扣的成功数与主评测一致。

S报告成功数/全部到达数、接纳率与分业务可靠性；M报告真实有线字节/PHY时间及归一化预约成本；V报告新mix、新负载和新对象合同下零更新表现。M/V是次要评测，不冒称已联合优化SMV，也不因S接近就选择性强调有利指标。R05提供四域和运行时标的建模语境，不为本算法提供最优性、收敛或优越性证明。

## 最终采用的RL配置

验证集选定 **legacy**：91维观测，8步单模型联合模态QR-DQN，原生稀疏奖励，复用每初始化32768次训练的不可改动模型。初始化11在新测试前固定为主部署单模型，不使用模型集成、专家规则回退或测试选择。所有候选版本都将模态作为动作；legacy指既有联合模态RL，不是请求预先带模态标签的老问题。

采用既有的单模型Masked Double QR-DQN，91维状态包含当前业务合同、17维资源在当前/1/3/6秒的已签预约、当前请求端点几何/关联及历史位移速度；候选45维，最多11动作。首帧速度置零，保留既定编码中的常量有效位，不将它视为真实速度已知的保证。32个回报分位数取均值选择合法动作，8步回报、gamma=1，原生到期SLA成功数作奖励。没有势函数整形、全体端点扩展或在途交付计数作为模型输入。

学习率1e-4、batch128、回放20000、warmup1024、每4步更新、目标网络1000步、宽96，探索16384步降到0.05；每初始化历史训练32768步。本轮复用经SHA256锁定的5个模型，在全新留出种子前向验证，不重挑原检查点。

## 选择、验收与三研究点接口

在新测试开启前，按共同初始化11/23/37的新验证成功率选择RL配方；所有初始化及失败修订完整报告。五条强规则仍在相同验证集调阈值，主要规则对照也只按验证选择。新常规测试27000—27029、分布外28000—28014，全部逐包重算SLA；完整统计与置信区间见report.md和analysis.json。

研究点1输出初始接纳、模态绑定、功能位置、资源预约和真实观测；研究点2以后预测资源需求，研究点3以后做运行期主动QoS调整。本轮不实现预测、CVaR或模态迁移，不套用R05自由能/Tikhonov收敛结论。模态到功能使用固定模板；资源数量由业务和协议包络计算，连续带宽与CPU份额优化不属于本轮。

候选设计与本轮1245184次新增训练的试错证据保存在development_design.md、development_formulation.md和完整报告中；未采用的模块不进入主方法。
