# 无档位切片分配：最终验证版优化协议

本轮是一次有界训练优化，不修改低空环境、模态执行、动作集、奖励、业务、资源容量和规则基线。参考版为simple-main-20261103：5个初始化，各训练32768步，按验证集选择各自的模型。旧测试结果不再用于选择参数。

唯一优化：从每个初始化的32768步终点继续训练32768步，将后期学习率从1e-4降低为5e-5，目的是减小近收敛阶段更新波动。不是新算法模块，不预设性能提升。重启时旧回放未保存，因此先用1024次新训练交互填充回放，再恢复梯度更新；该开销计入总65536步。全部初始化保留。

候选检查点为原先验证集选定的模型，以及续训49152/65536步模型。仍用92000—92029场景、48/80请求负载，以实际SLA成功率选择，每个初始化分别选择；同分取训练步数少者。续训无改善时保留原模型，不按测试成绩回退。

正式测试改用从未使用的96000—96059种子，两种负载；优化RL与参考RL各5个初始化，同时运行Greedy、Nearest、First-Fit，共1560个原生回合。两版RL在相同场景和相同初始化上配对，防止换种子造成的差异被误称为优化收益。

主指标：满足SLA的请求数/全部到达请求数。主比较为优化RL减Greedy，额外报告参考RL减Greedy与优化RL减参考RL。两种负载按场景种子共同重采样，RL初始化独立重采样；两版RL的初始化保持配对，20000次bootstrap。报告全部初始化、业务与负载，不把模型作为投票集成。

正式测试前冻结模型、源码、参数、选择记录、测试种子及分析源码。逐回合重新核对完整发包数、逐包截止时间、遥测交付方向、全生命周期预约与状态释放。最终报告只写实际观察到的收益；如果优化没有稳定提升，明确报告，不继续根据正式测试调参。

设计主线保持：低空背景（12架无人机、双AP、双边缘）→业务兼容的IP/EID-RLOC/NDN→动作掩码Double-DQN初始准入和功能位置选择。以实际成功合同数作为奖励；不用资源档位、超订、拉格朗日惩罚或价格先验。资源预测和运行期QoS保障是后续研究点，不并入本轮。
