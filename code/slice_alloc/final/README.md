# 面向低空智联的多模态网络切片技术

**最终方案：搭建低空背景 → 实现IP / EID-RLOC / NDN多模态网络 → 使用Masked Double-DQN完成切片初始智能分配。**

[三层设计与实现说明](DESIGN.md)给出各层做什么、请求进来怎样选择和分配。项目围绕这一条主线展开。

## 切片进来后怎么分配

切片提交业务、端点、生命周期、数据量/周期和SLA。控制器读取资源占用、当前关联与已观测位置，先排除不兼容或预约超额的配置，再选择拒绝或一个完整配置：模态、边缘以及适用的映射/缓存位置。原生执行器落实承载与资源预约，结束后释放资源，并依据真实逐包事件检查SLA。

最终采用Double-DQN，部署入口使用正式测试前预先指定的初始化11模型；研究统计包含全部3个初始化。

## 完整实验结果

在新的测试种子53000—53029上，48/80两负载按到达请求数合并，拒绝计失败：

| 方法 | SLA成功率 |
|---|---:|
| 最终RL：Masked Double-DQN | 79.38% |
| First-Fit | 77.94% |
| 近边优先 | 80.03% |
| Greedy | 79.35% |
| 固定配额 | 63.31% |

Double-DQN相对预先指定的Greedy差值 **+0.03个百分点**，配对95%区间 **[-1.07, +1.08]个百分点**。结果接近，**尚不能确认RL显著优于Greedy**；近边规则的平均成功率也更高。这一结论完整保留。

主对照为Greedy，常规基线固定为First-Fit、近边优先、Greedy和固定配额。价格规则79.77%、语义规则79.56%保留在[补充结果](experiment/report.md)，未根据成绩删除。

## 已完成的验证

- **180项测试全部通过**，包括掩码、真实学习更新、模型重载、失败重试、实际参数冻结、预注册哈希和时间戳相同等回归。
- **21个模型，各训练32,768步，共688,128次决策**：四种RL各3初始化，选定方法再重训三类消融各3初始化。
- **1,800个主测试/移动回合与120个压力回合**完成独立逐包SLA、业务方向及资源事务审计。
- **21个模型事件CSV精确重放一致**；全部保存模型的实际参数与配置相符，源代码、二进制、链接库、模型及 **11,814项产物哈希**通过核对。
- 新测试、移动、压力种子分别为53000、54000、55000段，与此前打开过的测试及短流程种子分离。算法及主对照在打开新测试前冻结，测试开始标记保存全部预注册内容的哈希快照。

切片预约属于账本约束，当前结果适用于固定高度、WiFi、小规模简化场景；预约本身不构成逐切片确定性带宽/时延保证。
