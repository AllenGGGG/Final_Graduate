## 设计合理性的实验证据

- 完整QR-DQN相对固定模态消融提高+2.76个百分点，95%区间[+1.88, +3.64]；这是探索性消融结果。
- 移动观测消融差值+0.83个百分点，区间[-0.24, +2.00]；资源日历消融差值+0.17个百分点，区间[-0.78, +1.09]。两者都未确认稳定正收益。
- 相同语义规则族下，共享池相对固定配额提高+16.95个百分点，区间[+15.52, +18.41]。该收益属于资源共享机制，不能归因于RL。
- 所选QR-DQN主测试主动拒绝仅 **3/11520**，当前实验没有展示清晰的长期准入取舍收益。

[当前实现设计](../ALLOCATION_FINAL.md)仍是简化低空场景中的三模态分配原型，预约属于账本约束。资源档位、真实逐切片保障调度、加权效用及分类最低服务约束尚未实现。上述结果可以支持原型的实现与对比评测，尚不足以支持强化学习分配方法的性能优越性。

- **15个模型事件CSV精确重放一致**；原生二进制、源代码、链接库及模型哈希校验通过。
