# 面向低空智联的多模态网络切片技术

第一部分完成：低空巡检、真实 IP/EID-RLOC/NDN 和切片初始智能分配。方法是独立深度动作价值 RL，复用独立 Double-DQN 起点并进行完整回报训练与验证选型；没有价格规则起点、专家轨迹、资源档位或对偶模块。

预指定主比较 RL−Greedy：**+1.005 个百分点，配对95%区间 [+0.299,+1.740]**。五个初始化 11/23/37/53/71 全部保留；正式测试为新种子 447000—447059、32/64/96 三负载，2520 回合。逐包 SLA、方向、预约、按请求 ID 的独立计数及 30 次模型重载重放全部通过，28 项代码测试通过。

本批预注册的六项门槛均通过：四条未经多重比较校正的区间下限大于0，加上两条违约率点估计不高于Greedy。这不等于全部比较经Holm校正后显著，也不是违约率统计不劣性的证明。具体见 analysis.json。论文仍须保留这些边界：

- Nearest 的配对区间为 [+0.094,+1.691] 个百分点，但补充比较 Holm 校正近似 p=0.063，不能写成校正后显著。
- 最终RL对初始独立RL为 +0.333 个百分点，区间 [0,+0.787]，尚不能单独归因于完整回报续训。
- 遥测成功率为 61.00%，低于 Greedy 的 64.27%；总体收益主要来自地图业务。原生模态规则违约率更低，但总体成功率较低。
- 本部分的切片是准入预约与配置，不是确定性带宽隔离；简化 EID-RLOC 不等同完整 LISP。不能外推为超过所有传统算法或每类业务均改善。
- 事后同协议补充中，模态感知Greedy为80.538%，高于RL的79.078%；RL减该规则为−1.460个百分点，未校正95%区间[−2.194,−0.708]。该规则使用独立开发集既定参数，不参与主模型选择。无准入阈值的指数资源价格规则另命名为`exponential_price`，不同于归档中的模态感知准入价格规则。详见[正式报告](report.md)。

参考模型已使用每初始化 65536 次训练交互，本轮另加 32768 次；每初始化总预算为 98304 次，不含验证、测试和早期开发，见 reference_training_provenance.json。两初始化先导测试没有并入本批统计。

Greedy另做了[独立优化验证](greedy-improvement/report.md)：开发/验证选定评分与准入阈值后，新550000系列测试中普通资源Greedy为77.743%、原模态感知Greedy为80.243%、选中规则为80.842%。相对原模态规则点估计增加0.599个百分点，三项共同Holm校正p=0.0725，尚未可靠证实这个小幅增量；轻负载成绩下降，违约率也未改善。900个新测试回合全部逐包审计，搜索记录完整保留。这些数据不与447000系列跨批直接比较。

模型和逐包轨迹保存在本地 `results/final`，未上传 Git；Git 提供原始汇总、协议、训练记录和文件哈希。早期试验归档于 `archive/firstpart-independent-rl-20261105`，更早的强规则研究在 `archive/firstpart-strong-baselines-20261104`。它们的负面证据保留，主目录只保留这一套结果。
