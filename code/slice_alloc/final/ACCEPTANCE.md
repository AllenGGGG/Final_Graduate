# 当前需求与版本验收

目标保持为“低空背景 → 多模态网络 → 网络切片智能分配”。第一部分采用单个Masked Double-DQN，先提供可写论文、可复核的分配建模与实验。预测与QoS分别在该基线上扩展，不同时改写第一部分后把所有变化混成一个结论。

第一部分验收：

1. ns-3中真实运行IP、简化EID-RLOC和原生NDN；各方法使用相同业务合同、移动条件、链路容量和资源可行性约束。
2. RL只选择准入、网络模态、边缘和映射/缓存位置；无虚假资源档位、超订、对偶模块或按接纳次数发奖。
3. 保留Greedy、Nearest、First-Fit，同一合法候选集，不通过禁止基线选某种模态制造优势；明确Greedy按即时归一化资源成本选择，不能把该规则族说成全部传统算法。
4. SLA成功数除以全部到达是主指标。拒绝计失败；同时报告接纳率、违约/全部到达、违约/已接纳、逐业务和全部初始化。
5. 恢复版需重新训练、重载、逐包SLA核验、方向核验、预约重放；汇总与原始事件一致，所有保留测试通过。
6. 论文中“相对Greedy有小幅优势”须有配对区间支持；若与Greedy相比成功率没有可靠改善、或违约风险恶化，则不作为满足需求的最终版本发布。不能挑初始化、删掉不利结果或将旧测试重复当新证据。

本次为已发表在Git的旧协议恢复复现，沿用其历史种子，不新增选型。上述验收是需求确认，不冒称在未知测试结果前重新预注册了历史试验。

后续若仍需重新设计：先在开发/验证环境定位失败来自物理可控性、动作作用、资源记账、状态信息或训练；一次只改变一项，保持对应对照。失败改动回退，已有证据保留。只有开发与验证结果支持，才冻结并使用新的独立测试种子评估；不得在已打开测试集上反复调到通过。

扩展版负面结果继续保留。旧版小幅优势说明它在该协议下优于所列规则，不意味着它在改变队列、轨迹、负载或基线后仍必然领先。恢复成功后先完成第一部分论文材料，再逐项设计后续研究点。
