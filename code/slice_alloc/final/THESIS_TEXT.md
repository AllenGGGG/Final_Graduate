# 可用于第一部分结果章节的文字

本研究在包含12架无人机、两个接入点和两个边缘节点的低空巡检仿真平台上，实现IP、简化EID-RLOC与原生NDN三种网络机制，并将切片初始分配建模为带可行性掩码的序贯决策问题。请求到达时，控制器依据当前合同、共享资源、候选配置和已观测移动/交付状态，选择拒绝或模态、边缘及映射/缓存位置。奖励由原生逐包交付结算的SLA成功合同数确定，拒绝仍计入总体成功率的分母。主方法采用独立深度动作价值学习，以此前独立训练的Double-DQN为起点，在完整回合结束后使用真实return-to-go进行有界续训；续训目标不含Double-Q自举，不将该实现描述为一种新的标准Double-DQN算法。

在五个初始化、新的60个测试场景以及32、64、96三档请求负载下，最终RL的总体SLA成功率为79.078%，Greedy为78.073%。预指定主比较的配对差为1.005个百分点，场景与初始化双重bootstrap的95%区间为[0.299,1.740]个百分点。RL接纳后违约率为9.037%，低于Greedy的12.773%。因此，在本实验协议下，RL相对即时资源贪心获得了小幅但有统计支持的总体改善，同时降低了已接纳业务的违约比例。2520个原生回合经逐包SLA、方向和预约重放核验，30次模型重载重放结果一致，28项代码测试全部通过。

收益具有业务差异。RL地图业务成功率为89.00%，Greedy为83.96%；遥测分别为61.00%和64.27%，说明总成功数目标没有保证每类业务都改善。Nearest的补充比较经Holm校正后近似p值为0.063，不应表述为校正后显著。最终RL相对初始独立RL仅增加0.333个百分点，区间为[0,0.787]个百分点，尚不能把这部分增量单独归因于完整回报训练。两个初始化保留续训前权重，是验证选型结果，不能称为这两个初始化获得了新的学习增益。

事后补充使用同一批447000系列测试场景，固定既有开发集选定的模态感知Greedy参数；其成功率为80.538%，RL相对该规则低1.460个百分点，未经多重比较校正的95%区间为[−2.194,−0.708]个百分点。把两个新增比较与原四项次要比较共同进行Holm校正后，该差异仍有统计支持。无准入阈值的指数资源价格规则为78.255%，RL相对其点估计较高，但在扩展比较族中的校正近似p值为0.0897。因此本实验不支持RL超过更强的模态感知规则。分负载看，RL相对即时资源Greedy的收益在轻、中负载较大，重负载96时尚未证实优势；分层区间为事后探索性结果。

本实验中的切片指准入预约与配置选择，未提供逐切片确定性带宽隔离；固定高度、小规模WiFi与缩比有线容量也限制了外推范围。结论应限定为该低空巡检平台和所列对照下的分配评测，不写成RL普遍优于传统算法、每类业务均改善或已经完成运行期QoS保障。
