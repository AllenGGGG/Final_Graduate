# 无档位切片分配：实际验证结果

主方法为Masked Double-DQN。5个初始化分别训练32768次决策；每个初始化仅按验证集选择检查点，全部纳入测试，无投票或择优初始化。

| 方法 | SLA成功率 | 95%区间 | 接纳率 | 主动拒绝率 |
|---|---:|---:|---:|---:|
| double_dqn | 79.06% | [77.53%, 80.51%] | 88.14% | 0.09% |
| greedy | 77.89% | [76.25%, 79.30%] | 89.69% | 0.00% |
| nearest | 78.18% | [76.54%, 79.58%] | 89.92% | 0.00% |
| first_fit | 76.90% | [75.21%, 78.52%] | 88.83% | 0.00% |

RL − Greedy：+1.17个百分点，配对95%区间[+0.28, +2.11]。

区间同时重采样场景与RL初始化，同一场景两种负载一起抽样。该区间未作多个基线比较校正，Greedy为预先指定主对照。

全部480个正式原生回合已重新核对逐包SLA、遥测方向、资源预约及场景一致性。完整测试日志见full-tests.log；模型、输入、逐包事件和决策保留在本目录。

本轮去掉档位、超订与拉格朗日约束，结果属于此简化环境；不能与旧版成绩直接相减归因。资源账本不提供逐切片确定性QoS保证。
