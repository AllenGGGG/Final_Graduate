# 面向低空智联的多模态网络切片技术：第一部分

本部分完成“低空巡检背景 → 多模态网络 → 切片智能分配”。请求到达时只作一次准入、网络模态绑定和功能位置选择，资源预测和运行期 QoS 调整留给后续部分。

## 低空场景与实际网络

平台有 12 架无人机、两个同信道 AP、两个边缘节点和任务平台。高度固定 80 m，4 架无人机巡检往返、8 架驻留，巡检速度为 5/8/11 m/s。ns-3 实际执行移动、关联变化、无线竞争、协议报文和逐包交付。无线为 802.11a 固定 24 Mbps，LogDistance 损耗加 120 m 覆盖限制；回源、跨边缘、AP 接入容量分别为 1、0.5、2 Mbps，链路时延 2 ms。这是用于研究分配的缩比平台，不把这些容量解释成真实部署推荐值，也不主张空地信道模型创新。

## 三种网络机制与切片合同

这里的“多模态”指不同网络机制共享同一空地资源池。

| 业务 | 合法网络机制 | 实际执行与合同 |
|---|---|---|
| 遥测上行 | IP | 1000 B，周期 20/40/80 ms；200 ms 内至少 95% 到达 |
| 命令下行 | IP 或简化 EID-RLOC | 512 B，周期 300 ms；600 ms 内至少 95% 到达；ID 机制执行映射和封装 |
| 地图对象获取 | IP 或原生 NDN | 每对象 4/8 个 1000 B 块，周期 2 s；800 ms 内全部块到达；NDN 执行 Interest/Data 与边缘缓存 |

同一请求在不同合法机制下使用相同有效载荷、产生时刻和 SLA，真实协议开销进入资源与交付记录。遥测只有 IP，因此其决策空间是准入与位置；不能把遥测成绩直接算作模态选择收益。EID-RLOC 是简化的身份与位置分离实现，不等同完整 LISP。

每个请求包含业务、端点、租户、开始时间、持续时间和 SLA。持续时间为 3/5/7 s，2—18 s 内到达，业务比例为 35% 遥测、25% 命令、40% 地图。32/64/96 三档负载只改变请求数量，不按 RL 成绩调整链路容量、业务权重或测试场景。

## 智能分配的状态、动作和目标

17 维账本记录有线方向容量、共享空口、映射条目、映射缓存和内容缓存。它用于准入预约和候选可行性检查，并不等于逐切片确定性带宽隔离。

请求到达时，动作是拒绝，或一个完整的 `(网络模态, 边缘, 映射服务器/缓存位置)` 配置。动作数组为 11 槽，未使用槽以及不兼容、关联不允许或资源不可行的配置由掩码屏蔽。所有方法使用同一候选生成器和约束。

状态使用当前请求、已承诺资源、候选资源与路径特征、活跃业务已观测交付计数、无人机位置/历史速度/关联。关闭未来预约日历特征；控制器可使用已知合同的结束时间检查预约，但不能读取未来请求或私有未来轨迹。当前接纳占用资源直至合同结束，会影响后来的请求；路径、缓存和映射位置也会改变真实交付结果。

目标是最大化每回合满足 SLA 的合同数：

\[
J(\pi)=\mathbb{E}_{\pi}\left[\sum_{i=1}^{N}\mathbf{1}(\text{合同 }i\text{ 满足 SLA})\right].
\]

拒绝和接纳后违约都记 0；成功率始终以全部到达为分母。同时报告接纳率、违约/全部到达、违约/已接纳，以及分业务成功率和其中的最小值，防止总体成绩掩盖弱势业务。

## 一个 RL 分配器及其真实训练方式

策略使用一个共享候选编码网络，为合法配置输出标量动作价值。编码器宽度 96，对候选作共享编码与池化，然后结合全局状态评分；执行和探索均服从同一个掩码。没有价格特征、规则起点、专家轨迹、资源档位、超订、辅助预测头或对偶模块。

起点是此前独立训练的 Masked Double-DQN。其来源遵循 [Double Q-learning 原论文](https://arxiv.org/abs/1509.06461)。本轮续训把短 n-step 自举目标换成已完成回合的完整真实回报：

\[
G_t=\sum_{k=t}^{T-1}r_k,\qquad
L(\theta)=\operatorname{Huber}(Q_\theta(s_t,a_t),G_t).
\]

原生奖励 \(r_k\) 是这次推进后新结算成功的合同数。只有回合完成后才把其历史转移和 \(G_t\) 入回放；决策时看不到未来结果。完整回报是[蒙特卡洛学习](https://mitpress.mit.edu/9780262039246/reinforcement-learning/)的基本思想。本实现使用逐步更新的探索策略和有限经验回放，属于近似深度动作价值控制，不主张无偏的离策略价值估计或收敛保证。

续训阶段的终局目标不包含 Double-Q 自举，论文应称为“独立深度动作价值 RL（完整回报训练，Double-DQN 起点）”，不能把仅有 Double-DQN 的代码类名当成这一阶段仍在使用 Double-Q 目标的证据，也不把它包装成新的标准算法。

每个初始化额外训练最多 32768 次决策，检查 8192/16384/32768；学习率 5e-5，回放容量 50000，batch 128，先填充 1024 次决策，每 4 次决策更新一次，gamma=1，探索率从 0.1 降到 0.02。初始独立 RL 的已有训练预算另行报告，不能把续训预算当作从零总预算。

## 对照、消融与冻结

| 对照 | 选择方式 | 回答的问题 |
|---|---|---|
| Greedy，预指定主比较 | 当前合法配置中归一化预约资源最少 | RL 是否超过即时资源贪心 |
| Nearest | 当前关联最近的边缘优先，以资源成本破同分 | 是否超过就近部署 |
| First-Fit | 第一合法配置 | 是否超过简单可行准入 |
| Native modality | 遥测 IP、命令 ID、地图 NDN，按资源成本选合法位置 | 语义映射规则能达到什么水平 |
| 初始独立 RL | 同一初始化的续训前权重 | 完整回报续训是否有额外收益 |

不以低下限规则代表全部传统算法，也不因为规则更强而删掉已有证据。更强规则和早期负面结果位于归档分支，不宣称已经被本表所替代或超过。

验证使用 442000—442059 的 60 个场景与三个负载。初始化 11/23/37/53/71 全部保留，按验证成功率最高选择检查点，同分取较早者；允许保留同一初始化的原 RL 权重。此前两个初始化的先导测试 445000—445059 已打开，因此只视为先导证据，不与本次新测试合并。

五个初始化确认测试另用全新种子 447000—447059。模型、源码、实际训练参数、验证选择和测试分析在正式测试前冻结；测试打开后不再调参。按场景和初始化双重 bootstrap 计算配对区间，三个负载按同一场景共同抽样。Greedy 是主比较，其他比较同时报告近似 p 值和 Holm 校正。更强的“全部规则区间为正且两种违约率不劣于 Greedy”发布条件另行保留，不能在测试后放宽。

## 论文边界

这项工作的材料是场景、真实三模态机制、统一合同与共享资源约束、初始分配建模、独立 RL 实现及完整对照审计。它不包含资源预测或运行期迁移，也不宣称每一类业务都改善、已实现确定性切片隔离，或 RL 普遍优于传统方法。结论以同目录正式报告和原始结果为准。
