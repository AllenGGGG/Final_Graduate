# 面向低空智联的多模态网络切片技术：第一部分最终设计

研究链条固定为：低空巡检场景 → IP/EID-RLOC/NDN多模态网络 → 网络切片智能分配。第一部分只在请求到达时作一次准入和配置选择；资源预测与运行期QoS控制后续单独研究。

## 低空背景与物理网络

采用12架无人机、2个同信道AP、2个边缘节点和任务平台。无人机固定高度80m，4架巡检、8架驻留；巡检采用原版水平往返轨迹，速度5/8/11m/s。ns-3实际执行无线竞争、关联切换、报文传输与协议行为。

无线为802.11a固定24Mbps，LogDistance损耗与120m范围限制。有线回源1Mbps、跨边缘0.5Mbps、AP接入2Mbps，链路时延2ms。这些是制造资源竞争的缩比实验设定，结论限定于小规模固定高度巡检场景，不主张低空信道模型创新。

## 多模态与业务合同

| 业务 | 候选网络机制 | 合同 |
|---|---|---|
| 遥测上行 | IP | 1000B，周期20/40/80ms，期限200ms，至少95%按时 |
| 命令下行 | IP或简化EID-RLOC | 512B，周期300ms，期限600ms，至少95%按时 |
| 地图获取 | IP或原生NDN | 每对象4/8个1000B块，周期2s，期限800ms，所有块按时 |

请求包含租户、业务、端点、开始和结束时间、SLA，不预先指定可选业务的模态。持续3/5/7s，到达时间2—18s；业务比例35%遥测、25%命令、40%地图。不同机制使用相同有效载荷、产生时间和SLA，记录映射、封装、Interest/Data等实际协议开销。

EID-RLOC为简化映射实现，不称完整LISP。IP下行没有连接迁移；移动实验中的机制差异受此适用范围限制。遥测只有IP，其决策是准入与位置，不能把遥测计作多模态选择的直接收益。

## 分配问题

共享资源由17维账本表示：10个有线方向、一个共享空口、两边缘各自的映射、映射缓存、内容缓存。账本用于准入预约和资源可行性检查，不等同于逐切片真实带宽隔离或确定性SLA保证。

每个请求到达时，从拒绝或合法的“模态、边缘、映射服务器/缓存位置”中选择一个配置。动作数组固定11槽，各业务实际可选项较少，未使用槽和不可行配置被掩码关闭。所有方法使用同一个候选生成器和资源约束。

状态包含当前合同、当前已承诺资源、已观测交付计数、端点当前位置、历史速度和关联，以及各候选的资源与位置特征。关闭未来预约日历特征；资源检查仍可使用已知合同的结束时间。未来到达和私有未来轨迹不进入策略。

接纳会占用资源至合同结束，影响后续请求；模态和位置影响路径、映射开销、缓存复用及真实交付。RL学习这些跨请求取舍。是否优于某条规则必须由该规则的同场景对照证明，不从动作数量直接推出。

## 主方法与对照

主方法为单个Masked Double-DQN，共享候选编码网络为每个配置输出标量Q值。探索、执行和Double-Q自举均遵守同一掩码。复用8步回放，网络宽度96、batch128、每4次决策更新一次、gamma=1。无资源档位、超订、拉格朗日惩罚、辅助头或预测模块。

奖励等于本次推进后新结算的真实SLA成功数，回合总奖励必须等于逐包重算的成功合同数。拒绝和接纳后违约都得0，拒绝仍进入总到达分母。

| 对照 | 选择规则 |
|---|---|
| Greedy，主比较 | 当前合法候选中归一化资源成本最小者 |
| Nearest | 当前关联最近的边缘优先，资源成本打破并列 |
| First-Fit | 第一个合法配置 |

三条规则同样允许使用业务兼容的所有模态，没有人工禁止某条规则使用NDN或ID。即时资源成本规则并不代表所有传统算法；结论限定于本协议所列对照。

## 训练、复现与论文指标

5个初始化11/23/37/53/71，初始训练32768决策，检查8192/16384/32768；验证集92000—92029、负载48/80。随后执行一次有界续训至65536，后期学习率5e-5、重新填充1024步回放，检查49152/65536。每个初始化在原验证最优模型与续训检查点中选验证成功率最高者，同分选较早者；全部初始化纳入测试。

原版480回合使用93000—93029与两负载；最终1560回合使用96000—96059与两负载，包含原版和续训版的同场景对照。此次沿用历史种子进行恢复复现，不把它计作新的独立证据，不根据测试结果继续调参。

主指标为SLA成功数/全部到达；同时报告接纳率、违约/全部到达、违约/已接纳、主动和强制拒绝、逐业务、逐负载及全部初始化。按场景种子聚类并同时重采样初始化计算配对区间。Greedy是预指定主对照，其余比较为补充。

逐包SLA、遥测方向、资源预约重放、模型重载与实际参数均独立核验。结果、区间与违约率以同目录report.md为准，不在设计中预设优势数值。续训对原版的增益若区间跨零，不包装成已验证的算法改进。

后续先固定这套第一部分基线，再逐项研究实际负载预测与QoS控制。每项都要保持相同物理环境的开/关对照；退化改动回退，负面结果保留，验证支持后才合入主线。
