# 最终设计：低空背景 → 多模态网络 → 受约束切片智能分配

## 1. 低空背景

平台固定为 12 架无人机、双 AP、双边缘节点；4 架执行巡检移动，8 架驻留，高度 80m，速度 5/8/11m/s。无线使用 ns-3 WiFi、LogDistance 传播和有限覆盖，链路容量是为了形成可控竞争的缩比实验参数。

## 2. 多模态网络实现

业务合同只描述业务和 SLA：

- 遥测：IP 上行；
- 命令：IP 或受限 EID-RLOC；
- 地图：IP 或原生 NDN，并可使用边缘缓存。

模态、边缘、server/cache 不写入请求合同，由分配器选择；原生 ns-3/NDN 执行承载，事件文件逐包重建 SLA。

## 3. 分层智能分配

请求到达时，上层策略选择接纳或拒绝；接纳后下层策略选择模态、边缘、server/cache 和资源档位（0.9、1.1、1.4）。入口整形器按档位调度该切片的实际发送，排队时间计入截止时间。

通信预约允许最多 1.12 倍的受控超订，并在 CMDP 代价中累计；映射条目、缓存容量和拓扑合法性始终硬约束。奖励是业务优先级加权的 SLA 效用（命令 3、遥测 2、地图 1）减去违约和超订代价。正式报告同时给出不加权 SLA 成功率，避免业务权重掩盖基本交付差异。

主算法固定为带动作掩码的分层 PPO，Greedy 是主基线，First-Fit、近边优先、固定配额是普通基线，价格和语义规则只作补充。训练前先执行原生档位敏感性、风险动作和离线乐观上界诊断；如果动作没有真实影响，停止训练。

## 4. 结果解释

本轮 PPO 为 73.34%，Greedy 为 77.32%，差值 −3.98 个百分点且区间不跨零。因此最终结论是：在当前低空多模态环境和这组约束下，分层 PPO 没有优于 Greedy；主要结论是受控超订、资源档位的真实执行、移动影响和基线对比，而不是 RL 优势。
