# 面向低空智联的多模态网络切片技术

当前实现只覆盖第一部分“智能分配”，不修改论文题目、研究点名称或遥测、命令、地图业务名称。第二部分资源预测和第三部分QoS保障不在实现范围内。本文描述已实现的仿真与分配原型；本次交付修复复现流程，不声称实现了此前讨论的资源档位、逐切片保障调度或加权服务约束。

## 场景与业务

任务平台、两个互连边缘、两个同信道AP、12架80米高度无人机组成简化低空智联实验平台。4架巡检、8架驻留，巡检速度5/8/11m/s；不将其表述为一般低空网络实测。AP间距150米，接入覆盖采用120米有限任务范围内的LogDistance损耗，指数2.5、1米参考损耗46.6777dB、发射功率20dBm。有限范围截断仍存在，不声称消除了硬覆盖边界。802.11a固定24Mbps，传播、竞争、重传、关联由ns-3执行；未引入速率自适应。

遥测从无人机上行到任务平台，仅允许IP；命令从任务平台下行到无人机，允许IP或受限EID-RLOC；地图允许IP下发或原生NDN获取，NDN可配置边缘缓存。跨模态保持相同应用有效载荷、产生时刻、接收端与SLA。ID实现注册、查询、更新与封装，不冒称完整LISP；当前IP下行准入时绑定定位，不包含IP连接迁移，因此不能将ID优势推广到所有IP移动方案。

保留原业务合同：遥测1000B、周期20/40/80ms、期限200ms；命令512B、周期300ms、期限600ms；地图4/8个1000B块、周期2秒、期限800ms。地图全部块按时，其他请求至少95%按时。生命周期3/5/7秒。48/80个请求在2—18秒到达；平衡混合比例为遥测35%、地图40%、命令25%。这些是研究合同，不是行业SLA标准。

回源1Mbps、跨边缘0.5Mbps、接入有线2Mbps、每链路2ms；共同空口准入预算0.65秒/秒。保留17维账本：10个有线方向、共享空口、两边缘的映射状态、映射缓存和地图缓存。映射/映射缓存每边缘8项，地图缓存16KB。遥测预约按上行方向计费；共享对象按授权租户、名称、版本和租约并集计费。平均工作量与保守路径包络不构成逐包可调度证明。

## 切片与决策

一个切片实例是租户、业务、端点、生命周期、SLA、模态、功能位置和预约组成的逻辑服务合同。请求到达时决定拒绝或一个完整初始配置，相关路径、映射与缓存由原生执行器落实。基础关联与正常定位更新属于协议行为，不是运行期主动优化。没有CPU处理模型、每切片无线调度或确定性QoS保证。

策略读取当前请求、当前及已签合同在1/3/6秒后的预约占用、当前/历史位置和关联、活跃合同的已发生交付计数以及候选资源特征。不读取未来到达或私有未来轨迹；释放日历不属于需求预测。候选掩码执行业务兼容与全生命周期资源可行性，不预知未来SLA结果。

目标为实际满足SLA的请求总数，拒绝计失败。候选感知PPO、Masked Double QR-DQN、标量Masked Double-DQN、候选感知A2C从头训练并比较，不预设算法优胜。PPO/A2C共享候选策略编码并对非法动作置零概率；两种DQN在探索、执行及自举时均使用掩码。标量DQN复用候选编码与多步回放，使用单个期望回报输出和Huber时序差分损失；QR-DQN使用32分位数与分位数回归损失。A2C是更新方式更简单的策略梯度候选。均无专家示范、规则先验、接纳奖励或势函数整形，gamma=1。QR分位数表示回报分布，不是第二部分的资源预测。

## 冻结实验

四种算法各3个初始化11/23/37，每个32768次决策，保存8192/16384/32768检查点；仅按验证选检查点并对全部初始化平均选择算法。选择后按相同预算重新训练固定模态、去掉移动观测、去掉未来预约日历三个消融，每消融3初始化。共21个模型、688128次训练决策。既有模型和旧测试成绩不参与本轮选择；同预算比较不等于穷尽算法或超参数最优性。

训练种子41000000—41999999，验证42000—42007，新主测试53000—53029，移动受控54000—54009，补充压力55000—55009。主测试使用48/80两负载。规则包括首次可行、近边优先、资源贪心、指数资源价格、业务语义与移动规则、固定配额。主对照预先指定为Greedy，First-Fit、近边优先、Greedy和固定配额构成常规主表；价格与语义规则保留在补充对比中，强弱不作为删除结果的依据。价格和语义规则仅在验证集选择阈值。固定配额将各有线方向及空口三等分；模态专属映射和缓存额度保持不变。

移动受控实验比较全部驻留、巡检但局限单AP、原巡检跨AP。物理容量和合同保持一致，非主测试的独立种子用于敏感性比较，不反向调参。

主指标：SLA成功请求数/全部到达请求数；附接纳率、接纳后违约、分业务成功率、强制/主动拒绝、实际有线字节、PHY发射时间、预约消耗和决策耗时。逐包重建SLA并验证遥测交付节点；对全部正式场景保存输入、决策、事件和结果。置信区间同时重采样独立场景及初始化，规则比较使用配对场景，初始化不作为部署集成。

结果由实际实验生成，不设成功率目标。对强规则优势未成立时如实报告；旧报告属于历史环境，不能与本轮直接相减宣称提升。

## 执行

使用安装了`requirements.txt`依赖的Python环境，在代码目录下执行`python -m slice_alloc all --workers 6`。此入口执行完整管线，包括压力实验、独立审计和报告；`freeze`、`train`、`evaluate`用于单独执行步骤，正式评测共用预注册。原生目录可通过`LOWALT_NS3_ROOT`指定，默认`~/.local/share/lowalt-ndnsim/ns-3`；需先将`execution/allocation_final_scenario.cc`复制到ns-3的`scratch/allocation-final-scenario.cc`并用waf编译目标`allocation-final-scenario`。

新实验默认输出位于`results/final/`，可由`LOWALT_ALLOCATION_OUTPUT`覆盖。协议、实际训练参数及依赖源码先冻结；正式测试前锁定算法、模型、规则、压力协议、辅助源码及部署约定。验证成功后才写入完成标记，失败或中断必须重试。正式测试开始标记保存全部预注册文件及规则参数的哈希快照，后续评测与审计核对该快照；文件系统同时间戳不会被误判为缺少预注册。最终实验报告及哈希清单仅在实验完成后生成到该输出目录，不覆盖本次交付验证结论。
