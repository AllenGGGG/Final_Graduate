# 面向低空智联的多模态网络切片技术：第一部分方法设计

状态：本轮实现与验证的设计依据。正式协议与实测结果写入results/lifecycle_ppo；历史74.24%实验独立保留，不作为本轮对照成绩。

论文题目保持《面向低空智联的多模态网络切片技术》，研究内容仍为智能分配、资源预测、QoS保障。本设计只针对第一部分。

## 方法：采用分层动作和生命周期表示的PPO联合分配

由一个PPO策略在同一次切片到达事件中，先决定是否接纳，再在接纳条件下选择功能部署。两个输出共同训练，不是两个独立算法，也不引入运行期迁移或额外协议。

### 1. 根据现有证据确定待检验问题

当前已核验PPO在全部21600个到达请求中接纳16927个、成功16035个，合计成功率74.24%、接纳率78.37%，有788次主动拒绝。资源价格规则在对应4320个请求中接纳3618个、成功3353个，合计成功率77.62%、接纳率83.75%。两者均在相同场景分布下评测。

这些数据说明PPO的接纳与部署仍有改进空间，但不能单凭主动拒绝数量断言拒绝错误，或认定全部性能差距来自拒绝。方法提出两个可证伪假设：接纳和部署的独立参数化有助于跨模态决策；按资源和到期时间保留预约结构有助于学习长期机会成本。两者都需同条件消融检验。

现有策略已有单独的拒绝评分头，但仍将拒绝和所有部署放在一个softmax中。新方法的区别是概率分解，而非仅增加拒绝评分头。

### 2. 课题与执行边界

保持双AP、双互连边缘、12架无人机（4移动、8驻留），IP／受限EID-RLOC／NDN三种固定语义切片共存。AP关联由无线机制产生，算法不选择AP。

- IP：选择汇聚边缘，执行地址通信。
- 身份位置分离：选择隧道入口和映射服务，真实执行注册、查询、封装及更新。
- NDN：选择服务边缘与缓存配置，真实执行名称请求和数据返回。

路径由这些部署及底层拓扑确定，不把不存在的独立路径选择写成算法动作。物理容量、发送合同、SLA及三模态资源成本对所有方法相同。保守预约继续依据公开允许AP范围，不读取真实未来轨迹。

### 3. 状态：保留当前条件和切片生命周期

网络输入分为当前请求、资源日历及候选部署三个部分。

当前请求保留模态、租户、端点、持续时间、载荷、发送周期、内容版本和SLA。对每个相关无人机保留当前关联AP、当前测量位置、由历史观测计算的速度及切换历史，避免只取多个端点的均值后丢失差异。未产生的观测不得补齐为真实未来位置。

资源日历按17种资源逐项编码容量、当前已预约量及未来1／3／6秒时已签合同仍占用的量。该日历仅重算已有合同，不包含新到达请求，也不预测实际未来负载。当前方案已有部分到期信息；这里将其与具体资源维度及候选需求联合编码，而不宣称首次加入生命周期。

每个候选携带真实功能位置、协议配置、新增资源占用、到期时间、共享缓存依赖及各时间点的已知预约余量。候选与资源表示使用小型注意力模块交互，学习当前切片主要竞争哪些资源；不加入手写价格分数。注意力不使用候选位置编码，候选换序时应只对应地置换部署输出。

编码宽度64，单层4头注意力起步；拒绝／接纳头读取当前请求和候选集合汇总，部署头读取每个候选及其关联的资源上下文。价值网络使用独立参数。

### 4. 动作：一个PPO策略的条件概率分解

令g为策略学习的接纳概率，q_j为在可行部署中选择第j个部署的条件概率：

P(拒绝 | s) = 1 − g(s)
P(部署j | s) = g(s) × q_j(s)
q_j(s) = masked_softmax(z_j(s))

没有可行部署时只允许拒绝；存在可行部署时，拒绝与所有可行部署都保留非固定的可学习概率。

这样，接纳概率不再因为IP有2个候选、NDN有4个候选而仅由一次联合softmax的项数直接改变。接纳头仍可根据候选内容和可行性学习调整概率，不保证候选数量完全不会影响策略。

训练记录实际联合动作概率。接纳时log概率为log(g)+log(q_j)，拒绝时为log(1−g)，PPO重要性比率必须使用这个联合log概率。熵为二元接纳熵加g乘条件部署熵，不把两个阶段随意当作两个环境时间步。

正式执行预先固定为顺序确定性决策：g≥0.5则接纳并选择q_j最大的部署，否则拒绝；并列按固定候选标识处理。它不同于对展开后的联合概率直接取最大值，代码、验证及正式评测必须一致，不能临时换规则。本轮主实验比较预先声明的确定性执行方式，不把它称为随机策略的期望性能。

### 5. 目标与训练

主目标仍是全部到达请求中满足SLA的数量最大。奖励采用原生仿真已结算的成功数，可除以同一个正常数调整单位；不按接纳立即奖励，不使用价格惩罚、规则示范或残差。折扣gamma=1，完整服务结算必须在episode终止前返回。

训练仍采用PPO裁剪目标，策略与价值编码分离。起始预算与现有基线一致：5个初始化、每个65536次原生交互，16384／32768／65536步保存完整模型，只按独立验证集选择，保留全部初始化。训练稳定性与超参数只在训练／验证集上处理，不查看最终测试后反复挑选方案。

该方法是PPO在本课题动作结构和状态结构上的适配，不宣称提出全新的强化学习算法。

### 6. 必须完成的验证

先验证联合概率和为1、无可行候选时拒绝概率为1、两个决策头均有非零梯度、手写价格输入不参与评分、候选换序输出等变、未来请求／轨迹扰动不改变过去观测，以及完整模型重载后概率／动作逐项复现。

主实验比较本方法、两个消融、近边规则、资源贪心、资源价格规则及固定配额规则；规则仅作外部对照。两个消融均保持其余网络和训练预算一致：将分层概率改回联合softmax，检验动作分解；移除逐资源到期日历，保留当前占用、当前请求持续时间与原有合同摘要，检验新增日历表示。不能用不同旧版本之间的数字直接归因。

最终测试使用冻结前未查看的新种子，所有方法共用相同场景。报告全部到达请求的SLA成功率、接纳率、分模态成绩、初始化差异、配对置信区间和运行成本。对主动拒绝的反事实评测仅作事后分析，不进入线上观测，也不能把每个反事实的最好部署当成在线基线。

模型选择恢复完整检查点；训练预算和所选步数分别记录；评测前断言实际策略参数与清单相同。源码、冻结协议、模型、逐包审计与发布文档必须保持同一指纹链。没有“保证不低于规则”或必达某个成功率的承诺。

### 7. 与后两部分衔接

第一部分只输出初始部署、资源预约和真实执行记录。第二部分以后预测当前未知的资源需求变化；已签合同的到期重算不算资源预测。第三部分以后利用监测和预测调整运行中的配额、路径或功能位置。三部分累计效果应在同一环境统一比较，不能预填第二、三部分的成功率。
