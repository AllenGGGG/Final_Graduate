# 第一部分验收结果

唯一设计与结果见 `final/README.md`、`final/DESIGN.md`、`final/report.md`。

本次完成了真实三模态 ns-3 交付、相同候选与掩码的五种方法对照、五个独立初始化、初始 RL 对照、28 项代码测试、2520 个新正式回合逐包 SLA/方向/预约核验、30 次模型重载重放，以及按请求 ID 重算业务与模态计数。

预指定的主比较支持 RL 总体成功率高于 Greedy，且两种违约率均未恶化。六项预注册区间/违约条件全部通过；它不等价于所有补充比较经多重校正后均显著。Nearest 校正后证据不足，遥测仍弱于 Greedy，续训本身的增量区间触及零。这些限制保留在最终报告中。

旧设计、失败试验及两初始化先导已经归档；第一部分没有混入资源预测或运行期 QoS 模块。模型和逐包数据未进入 Git，完整获取或重新生成的方法见复现说明。
