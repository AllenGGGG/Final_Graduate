# 面向低空智联的多模态网络切片技术

本轮仅研究第一部分“智能分配”。资源预测和运行期QoS保障保留原有研究边界。

## 方法及实验合同

选用QR-DQN价值学习路线，预测离散动作的长期回报分布，以平均回报选择动作。Double-Q将在线网络选动作与目标网络估值分开。多步回报、均匀经验回放和动作掩码均为通用学习机制；不宣称这些既有组件为原创算法。

网络使用共享候选编码、集合均值／最大值汇总和独立拒绝输出，处理不同数量的合法部署。训练不读取协议名称来写决策规则，不使用规则示范、固定拒绝偏置、价格先验或手写残差。输入在进入网络及经验回放前删除外部价格规则的评分。掩码同时用于随机探索、执行和目标动作选择。回合终止时排空多步回报，避免跨回合串接。

保持双AP、双互连边缘、12架无人机（4移动、8驻留）和IP／受限EID-RLOC／NDN三模态切片合同。环境源码、物理容量、SLA、流量、移动、保守预约和候选保持原样。算法决定初始接纳、拒绝和功能部署，不选择无线关联，也不运行期迁移。所有模型只能读取当前及历史信息和已签合同；合同到期重算不是第二部分的需求预测。

## 预先声明的训练与选择

训练奖励直接采用原生结算的SLA成功数，不缩放；gamma=1，不改变全部成功数目标。上一轮PPO的奖励单位为成功数／80，比较时明确披露。QR-DQN使用64分位数、宽度128共享MLP、Adam、batch128、经验回放20000、warmup1024、每4次交互一次更新、目标网络每1000步硬同步、梯度范数上限10。探索从1线性降到0.05，固定在绝对16384步结束，不随检查点阶段重新开始。

先在训练种子7000000—7999999上，用两个初始化和32768步筛选三个预定配置：学习率1e-4／3步回报、3e-4／3步回报、1e-4／8步回报。每个在16384／32768步验证。筛选种子11000—11007，按两个初始化各自最佳检查点的平均SLA排序；并列按预定配置顺序。完整保留筛选结果和额外预算。

选定配置后，5个初始化11、23、37、53、71在8000000—8999999上从头训练131072步，在32768、65536和131072步保存。独立选择集11100—11115：长预算结果从三个检查点选择，等65536步预算结果仅从前两个选择；相同时选早者。两者共享一次训练轨迹，不将它们称为独立训练。所有初始化进入最终统计，不挑最好者。完整模型重载后必须重现所选验证记录。

新正式测试种子11200—11229，模型及配置选定后才打开；64／80请求场景均测试。报告QR-DQN长预算、等65536步预算、上一轮PPO所选5个模型在同一新测试集上的表现，以及4个传统规则。PPO检查点原样冻结，不复用旧测试成绩；其已花费训练预算单独记录，不声称这是一场经过完全相同超参搜索的算法竞赛。

共享竞争11300—11305，移动受控11400—11402；所有种子组互不重叠。均衡及模态偏重场景只改变请求构成，物理容量不变。算法收益、共享池收益和真实移动机制分别报告，不互相替代。

## 验证与交付

先完成单元测试和端到端小规模训练、保存、重载、评测、报文审计及文档导出，再运行正式实验。冻结环境／算法／实验脚本、测试、依赖实现与原生二进制。逐包重建全部正式SLA、检查同场景输入、实际模型参数与权重变化，并精确重放每个所选模型。按场景及初始化双重重采样计算95%区间。

报告主指标为满足SLA请求数／全部到达请求数，拒绝计失败，附接纳率、分模态、分负载、方差、决策成本及全部选择记录。不能依据验证集微小收益声称保证超过规则，也不通过改变环境难度凑成功率。

方法依据：[QR-DQN原始论文](https://arxiv.org/abs/1710.10044)、[Double DQN原始论文](https://arxiv.org/abs/1509.06461)、[SB3-Contrib 2.7.1](https://sb3-contrib.readthedocs.io/en/v2.7.1/modules/qrdqn.html)。本轮检验该路线的适用性，不声称已经找到所有RL算法中的最优者。
