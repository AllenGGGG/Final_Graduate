# 面向低空智联的多模态网络切片技术

唯一实施方案：低空巡检 → IP/EID-RLOC/NDN → A初始分配 → A+P实际负载预测 → A+P+Q运行期队列控制。

12架无人机，双AP、双边缘，同信道802.11a固定24Mbps，LogDistance叠加120米范围限制；固定80米高度，AP高10米。四架巡检机采用二维矩形waypoint，其余悬停。测试驻留、局部移动、跨AP移动；只主张小规模低空巡检仿真，不主张信道模型创新。

遥测IP上行、命令IP或简化EID-RLOC下行、地图IP或原生NFD/NDN获取。遥测单独报告，其动作只有准入和位置。17维预约包含十个有线方向、共享空口、映射/缓存资源；预约不等同于SLA保证。

五条双向有线链路的设备发送队列统一采用按切片DRR，基础量子512字节、权重1、共享100包缓冲。NDN共享物理报文按最早活跃匹配切片归账一次；共享缓存不复制流量、不重复计费。这是有限隔离和服务区分，不是每受益切片的硬带宽保证。

A：Masked Double-DQN逐候选打分，至多11动作，选择拒绝/模态/边缘/映射与缓存位置。状态仅含公开合同、已接纳资源、可观测运行计数、位置速度关联。无未来预约日历、档位、超订、对偶惩罚或奖励塑形。最终SLA成功得1，拒绝/违约0，累计回报最大化。

P：每100ms采样设备队列实际到达字节（含协议开销，入队丢弃前计数），过去3秒负载和队列长度预测未来1秒十方向负载率P50/P90。GRU(20→32→20)，预测在准入事件更新，作为A+P额外状态重新训练；A中对应特征为零。训练、验证按完整回合划分；包含启动时零填充历史。对照持续值、移动平均、EWMA，基线P90残差只在验证集校准。报告MAE、分位数损失、覆盖率。标签为未来实际流量，不是合同账本。

Q：每100ms检查队首等待。被动阈值为0.25×截止时间；预测版额外在P90>0.8且等待>0.1×截止时间时触发。增强权重4，最低1，冷却0.5秒。预测更新超过1秒即失效，回退被动。只改有线队列，不迁移，不切换运行期模态；无线失联不在其控制范围。

开发集先检查1.0/0.75/1.5倍有线容量，依序选第一个满足负载区分度的配置：32请求强制拒绝率≤8%，96请求强制拒绝率8%—40%，总成功率差≥5个百分点。均未满足则中止正式训练，报告诊断，不按RL成绩调容量。

负载32/64/96。混合三种移动条件训练、分条件测试。A、固定原生模态、无显式移动观测、A+P各8初始化、每个65536决策。检查点32768/65536按24个验证种子（每个一个移动条件、三档负载）选择，全部初始化纳入测试；不选最优初始化、不投票。无移动观测仍保留相同可行动作掩码，因此不声称彻底移除了移动的间接影响。

业务原生模态规则：遥测IP、命令ID、地图NDN；原生不可行回退其他合法模态，NDN优先有缓存，其余按资源成本。资源Greedy与First-Fit使用同一合法候选集。模态感知Greedy评分=当前负载加权资源成本+α排队/截止时间+β移动绑定风险+δ无缓存项；24组参数在相同验证集选择，完整报告。无未来真值或事后成功率。

正式测试60个新种子×三负载×三移动条件；无移动观测不测试驻留，其余均完整测试。A+P同一模型分别测试固定权重、被动控制、预测控制。主比较A对模态感知Greedy；四项次要比较Holm校正。报告逐业务及最低业务成功率、逐初始化均值中位数范围、逐负载、逐移动条件、拒绝分类和调整开销。测试前冻结所有源码、参数、模型与分析脚本。只按结果作结论，不预设RL或预测/QoS必然提升。
