# 面向低空智联的多模态网络切片技术

论文研究内容保持：**智能分配、资源预测、QoS保障**。本次只完成第一部分。低空巡检、三种网络模态和PPO是第一部分的场景、建模和求解选择，不替代论文题目或其他研究内容。

## 第一部分：低空智联下的多模态网络切片智能分配

### 研究问题

在无人机移动引起接入变化、三种网络机制竞争同一基础设施的条件下，对在线到达的服务切片决定是否接纳以及功能部署，尽可能提高全部到达请求中满足SLA的比例。拒绝也是有效的学习动作；第一部分不主动重配置已经接纳的切片。

### 场景及三种模态

```text
                 地面任务平台
                  /       \
                边缘1 ── 边缘2
                  |        |
                 AP1      AP2
                   \      /
                    无人机群
```

12架无人机中4架巡检移动、8架驻留，固定高度80m；巡检速度取5、8、11m/s。两个AP共用无线竞争域。原生ns-3无线协议产生关联和切换；PPO不选择AP。边缘间链路使近侧和远侧功能部署具有真实的资源与路径差异。

| 网络模态 | 服务语义 | 可执行部署选择 | 特有资源 |
|---|---|---|---|
| IP地址通信 | 周期上行流表示巡检视频／遥测负载 | 汇聚边缘节点 | 转发带宽、共享空口 |
| EID/RLOC身份位置分离 | 移动端点保持稳定标识的任务下发 | 隧道入口、映射服务节点 | 映射表、查询缓存、注册与查询开销 |
| NDN名称内容 | 同租户同名同版本地图获取 | 服务边缘、缓存配置 | 内容缓存、名称协议开销 |

三种服务需求分别固定，不要求协议互换。EID/RLOC为参考身份与位置分离思想的自定义受限机制，IP是其底层承载，不声称完整LISP标准实现。NDN缓存命中仍需消耗最后一段无线传输。不同业务的SLA与流量不同，不把分模态成功率用于证明某个协议全面更好。

每个请求是有限生命周期的逻辑服务切片，包含租户、模态、端点、发送合同、SLA、部署及预约，具有独立实例与释放语义。同租户、同内容、同版本的缓存租约可共享。

### 统一资源与信息边界

17维账本涵盖10个有线方向、1个共享无线发送工作预算、双边缘映射状态、映射缓存和内容缓存。部署必须真实改变协议执行路径及功能位置。缓存按对象并集计费，已签合同到期后释放。

可观测信息为当前请求、当前原生位置与关联、历史观测、当前缓存和已签合同。已签合同的到期日历是已知信息，不称作预测。真实未来轨迹和未到达请求不进入观测或候选生成。

候选对公开任务活动范围允许的AP情形进行保守预约，不读取真实未来切换时刻缩减资源。移动观测进入PPO网络，资源包络与移动观测属于不同环节。可行性掩码只排除超容量或不可执行的部署，拒绝始终合法。

### 求解方法：分层动作与逐资源生命周期表示的PPO

动作是拒绝或一个可执行部署：IP最多2个，身份位置分离最多4个，NDN最多4个。一个PPO在同一个请求到达事件中，学习接纳概率g及接纳后的部署条件概率q。拒绝概率为1−g，部署j的概率为g×q_j。不存在可行部署时只允许拒绝。该参数化使接纳概率不由联合softmax项数直接决定；接纳头仍可根据候选内容和数量学习调整概率。

训练按真实联合动作计算PPO概率比及熵，两个输出共同更新，不拆成两个环境时间步或两个算法。确定性执行固定为g≥0.5时选择q最大的部署，否则拒绝；不同于对展开后的联合概率直接取最大。并列按稳定候选次序处理。

不叠加手写价格规则、不设固定拒绝分数、不使用残差系数，不进行示范预训练或奖励塑形。外部资源价格规则计算出的标量也被排除出PPO网络输入；它仅供对照方法使用。PPO与规则共用相同物理约束和服务合同。

17种资源各自编码容量、当前占用及未来1／3／6秒的已签合同占用；每个部署编码逐资源峰值需求及相同时刻的新增预约量。查询只针对已有合同，到期重算不是预测。逐端点观测保留实际位置、当前关联和历史差分速度，端点集合及候选集合不使用顺序位置编码。资源身份有独立可学习编码。宽度64、4头注意力让每个候选读取其资源上下文，接纳头读取请求和候选集合汇总。

策略与价值网络使用独立编码器，避免价值回归直接更新策略特征。PPO仍采用标准裁剪目标；不宣称提出新的PPO算法。此设计提出可检验的结构适配，不能从架构直接推导性能提升。

两个等预算消融：no_hierarchy保留全部输入和编码器，仅将分层概率改回联合softmax；no_calendar保留分层动作，移除所有显式未来逐资源采样，保留当前占用、当前请求持续时间及原有合同数量和到期摘要。这是逐资源日历消融，不是去掉所有生命周期信息。

训练奖励为原生仿真已结算的SLA成功数除以常数80；这一常数只改变奖励单位，不改变同一轨迹优劣。正式评价使用未缩放的原生SLA统计，不增加接纳奖金或资源惩罚。

固定超参数：学习率3e-4，rollout1024，batch128，每次10轮更新，gamma=1，GAE lambda=1，entropy=0.01，clip=0.2，target KL=0.03，网络宽度64。主方法与两个消融各用5个初始化11、23、37、53、71，从头训练65536步，共983040次原生交互。

### 模型选择与冻结

每个初始化在16384、32768、65536步保存完整算法检查点，只按独立验证集的SLA成功率选取；相同时选较早检查点。保留全部初始化，不挑最高者。所选检查点重新从磁盘加载并重复验证，必须逐项复现。网络架构参数、实际训练步数、优化器和权重随检查点完整保存，不靠运行期属性或手动赋值修复加载。

训练场景种子6000000—6999999；验证10100—10115；新主测试10200—10229；共享竞争10300—10305；移动机制10400—10402。训练、验证、测试互不重叠。9000—9029继续保留给三部分累计验证。测试集在全部模型选定和协议冻结之后打开。

冻结源码、合同、测试、导出器、原生二进制及全部模型指纹，源码快照与每个阶段记录一致。测试日志由流程自动生成。报告不另改训练指纹，也不通过直接调用发布函数绕过冻结核验。

### 三组实验

1. **智能分配主实验**：64／80个请求在2—18秒到达，三模态比例约各三分之一。主方法、两个消融各5个初始化，与近边优先、资源贪心、资源价格规则及固定配额规则比较，共1140次评测。主指标为满足SLA请求数／全部到达请求数，拒绝计失败，同时报告接纳率、分负载与分模态成功率、资源压力、决策时间及初始化方差。配对区间同时重采样场景和初始化，不预设RL领先或指定成功率。
2. **真实移动机制实验**：在固定部署下比较驻留、服务窗口移动但不切换、服务窗口跨AP，共54例。业务与容量固定，速度为0／5／11m/s。核对实际AP切换、按时交付及控制开销；不将速度和切换的共同影响全部归因于切换，也不要求移动观测必然提升策略成绩。
3. **三模态共享竞争实验**：均衡、IP占优、身份位置分离占优、NDN占优四种请求构成，保持物理容量一致；同一资源价格规则比较共享池与固定三等分通信配额，共96例。模态专有状态和内容缓存不强行分给其他模态。该对照反映共享资源管理，不属于PPO学习收益，不声称实现无线硬配额调度。

按原始报文逐项重建全部1290次正式实验的SLA，对所有方法核对相同输入、可行性与观测范围，重载15个模型执行代表性原生精确重放。先做覆盖训练、模型选择、重载、分析、审计和Word导出的端到端小规模冒烟实验，再执行正式流程。检查联合概率、梯度、候选换序等变、端点换序不变、实际加载参数和未来信息隔离。

### 三项研究之间的接口

第一部分输出初始部署、预约、实际通信、状态、缓存和交付记录。第二部分以后预测尚未知晓的实际资源需求或运行开销，不能把重算已知发送合同当作预测。第三部分以后利用监测和预测调整配额、路径或功能部署，并记录调整开销和SLA改善。

资源预测和运行期QoS保障尚未实现，不预先赋予83%—89%或90%—93%的结果。若后续增加未知需求波动等机制，三部分应在同一扩展环境统一重跑累计比较。

### 研究边界

当前是固定高度、受限传播、有限部署候选的服务切片模型，不声称完整多模态网络体系、任意虚拟网络编排或安全硬隔离。保守平均资源预约不等于无线逐包硬保证。低空移动、网络模态、切片合同和资源竞争之间必须有可执行对应关系；课题合理性不以某个特征必然提高成功率为条件。
